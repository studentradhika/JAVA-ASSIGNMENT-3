 Features

 Add new students

 Search student by roll number

Validate marks (0–100) using custom exception
 Calculate average marks

 Display Pass/Fail result

 Handles invalid input and errors gracefully

 Supports up to 10 students

 Technologies Used

Java

Object-Oriented Programming (OOP)

Exception Handling

Arrays & Loops

 Project Structure
├── ResultManager.java
├── Student.java
└── InvalidMarksException.java

▶ How to Run the Program
1️ Compile the program
javac ResultManager.java

2️Run the program
java ResultManager
